
This directory contains files for docking for the following test set systems:

1) 140 RAS systems

https://doi.org/10.1021/acs.jcim.4c01623

2) 43 DUDE-Z systems

https://doi.org/10.1021/acs.jcim.0c00598

3) 207 covalent systems from 'Comparative Evaluation of Covalent Docking Tools' by Scarpino et al.

https://doi.org/10.1021/acs.jcim.8b00228
